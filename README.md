# 门店地图插件（飞书多维表格仪表盘）

在飞书多维表格仪表盘中，根据多维表的经纬度数据渲染门店点位地图。底图使用**本地行政区划 GeoJSON（阿里云 DataV.GeoAtlas）自绘 SVG**，不依赖第三方地图 SDK，**不需要地图 key**，可离线加载。

## 一、本地开发

```bash
npm install
npm run dev        # 默认 http://localhost:5173
```

### 在飞书里调试

1. 打开多维表 → 仪表盘 → **+ 添加组件 → 插件 → 更多**（插件市场）
2. 右上角 **添加自定义插件** → 服务地址填 `http://localhost:5173` → 确定
3. 插件以 iframe 加载，改代码 Vite HMR 会实时刷新

### 脱离飞书调试 UI（可选）

本地浏览器打开 `http://localhost:5173/?mock=1` 会走 mock 数据（真实 52 条门店），不调用飞书 SDK；
底图是仓库内置的 GeoJSON，**无需任何地图 key 或白名单**，开箱即用。

- `?debug=1` 打开诊断面板（环境 / 配置 / 取数 / 错误），飞书里排查白屏时使用；`?mock=1` 默认也会打开。
- `?debug=0` 可强制关闭。

> `src/mock.ts` 里的 mock 点位是从「门店经纬度」导出的**真实 52 条门店数据**（便于本地核对坐标是否落在正确位置）。门店位置属公开信息，但如果不希望它进入公开仓库，把 `RAW_POINTS` 换回示例坐标即可。

> 注意：服务地址只能填 `localhost`，不能填局域网 IP。https 页面嵌入 http iframe 仅对 localhost 豁免。

## 二、底图数据

底图是随项目发布的本地 GeoJSON，位于 `public/maps/`：

- **366 个文件、约 30 MB**，文件名即行政区划 adcode（`100000` 全国、`440000` 广东省、`440300` 深圳市……）
- 数据来源：阿里云 **DataV.GeoAtlas** 行政区划数据（国内合规来源）
- 每个要素 `properties` 含 `name` / `adcode` / `center` / `centroid` / `level` / `parent` / `acroutes`
- 地图按当前筛选层级**只加载对应一个文件**：全国 → 省 → 市，并带多级回退链，不会一次加载全部
- 坐标系 **GCJ-02**，与飞书地理位置字段一致，无需转换

投影为 Web Mercator，由 `src/geo.ts` 完成加载、解析、投影和路径生成；地图交互与标签渲染在 `src/components/MapView.tsx`。

## 三、插件配置

### 基本配置

| 配置项 | 说明 |
|---|---|
| 数据表 | 选择包含门店坐标的数据表，例如「门店经纬度」 |
| 门店名称字段 | 可选；点击/悬停点位时气泡显示的标题 |
| 坐标来源 | `经度字段 + 纬度字段`（文本/数字均可）或 `单个地理位置字段` |

### 可选-地图筛选

| 配置项 | 说明 |
|---|---|
| 省份字段 | 可选；配置后地图顶部出现「省份」下拉，并切换到该省视图 |
| 城市字段 | 可选；配置后出现「城市」下拉（随所选省份联动），选中后切换到该市各区县视图 |
| 品牌字段 | 可选；配置后出现「品牌」多选下拉，并决定点位图标（圆点取品牌主色、市视图用品牌 logo） |
| 门店功能字段 | 可选；配置后出现「门店功能」多选下拉 |
| 门店类型字段 | 可选；配置后出现「门店类型」多选下拉 |
| 经营模式字段 | 可选；配置后出现「经营模式」多选下拉 |

### 可选-保有量

| 配置项 | 说明 |
|---|---|
| 保有量子表 | 可选；选择同一 Base 下的保有量子表，选「不显示保有量」则关闭 |
| 保有量-省份字段 | 子表内的省份字段（用于与地图省名匹配） |
| 保有量-城市字段 | 子表内的城市字段（用于与地图市名匹配） |
| 保有量-区县字段 | 子表内的区县名称字段（用于与地图区县名匹配） |
| 保有量数值字段 | 子表内的数值字段（原值显示） |

> 选了保有量子表后，**省份 / 城市 / 区县 / 数值四个字段必须配齐**，否则保存时会提示且不生效。

配置保存在仪表盘的 `customConfig`，每张仪表盘组件独立保存。

## 四、筛选与显示规则

### 筛选联动（品牌为枢纽）

- **品牌**选项：仅受已选省份 / 城市收窄
- **门店功能 / 门店类型 / 经营模式**：各自受省份 / 城市 + 已选品牌收窄，**三者之间互不约束**
- 选择省份会自动清空已选城市，便于逐级下钻
- 所有多选下拉支持关键词搜索、勾选多个值；门店功能 / 类型 / 模式的「全部xx」表示不限制该项（品牌例外，见下）

### 品牌默认不选，未选品牌不显示点位

这是当前的产品设定：

- **初始状态不显示任何门店点位**，品牌下拉默认显示「选择品牌」
- 选中 1 个或多个品牌后才显示对应点位；下拉里的「清除选择」回到不显示状态
- 若数据源本身没有品牌字段，则不做此限制，直接显示全部点位

### 点位与行政区名称

| 地图层级 | 点位样式 | 行政区名称字号 |
|---|---|---|
| 全国视图 | 品牌主色 **9px 小圆点** | 省份名基准 7px |
| 省视图 | 品牌主色 **9px 小圆点** | 城市名基准 9px |
| 市视图 | 品牌 **logo** 图标 | 区县名基准 9px |

- marker 与文字都做了**反向缩放**：marker 视觉大小恒定；行政区名称放大时**封顶 12px**，缩小不受影响
- 名称无描边光晕，纯深色文字
- 地图交互：**滚轮缩放**（以光标为中心）、**拖拽平移**、**双击复位**

### 保有量显示（仅城市视图）

- 仅在**选中城市、切换到区县图层**后显示
- 按 `省 | 市 | 区县` 归一化后精确匹配保有量子表；**匹配不到或数值缺失就不显示**
- 显示在区县名正下方，品牌蓝 `#2f6fed`，**原值显示**（无千分位、无单位）
- 字号：默认 **8px**（比区县名小 1px），放大时有效字号**封顶 11px**
- 全国视图 / 省视图均不显示保有量

## 五、品牌标识与配色

- 品牌徽章 SVG 位于 `src/logos/*.svg`，覆盖小鹏 / 理想 / 特斯拉 / 零跑 / 比亚迪 / 小米 / 吉利银河 / 蔚来 / 极氪
- 圆点与标记颜色**直接从对应 SVG 中提取主色**（`brandPrimaryColor`），保证与 logo 一致
- `src/brandColors.ts` 的 `BRAND_COLORS` 作为兜底：仅当 SVG 取不到颜色时使用；未知品牌按名称稳定分配备选色
- 没有徽章的未知品牌，回退到品牌色水滴标记

## 六、坐标系

门店经纬度与本地 GeoJSON 同为 **GCJ-02**，正常情况下无需转换。

首批数据上线前，建议挑 1-2 个已知门店对比实际位置确认；若整体偏移约几百米到 1 公里，通常是坐标系问题或经纬度字段填反了（配置面板已不提供「颠倒」开关，直接在配置里把经度/纬度字段对调即可）。

插件会过滤掉超出中国及周边范围（经度 70-140、纬度 0-60）的脏数据；取数明细（总数 / 有效 / 跳过）可在诊断面板（`?debug=1`）查看。

## 七、部署到 GitHub Pages

1. 仓库设为 **Public**，Settings → Pages → Source 选 **GitHub Actions**
2. `git push` 到 **`master`** 分支，`.github/workflows/deploy.yml` 会自动构建并发布
3. 部署完成后地址为 **`https://chensjfish.github.io/V1/`**，把它填回仪表盘的插件服务地址即可

调试期建议保留两个插件实例：一个指向 `localhost:5173`（本地联调），一个指向 Pages 地址（线上验证）。

## 八、已知限制

- 通过**独立分享链接**打开的仪表盘不会展示插件
- 插件默认仅添加者本人可见，要开放给他人需提交官方发布审核
- 全国视图会显示所选品牌的全部点位，一线城市密集区域圆点会重叠，暂未做聚合；数据量到数千点以上时建议改为聚合展示
- 底图数据约 30 MB（366 个文件），但地图只按当前层级加载单个文件，不会一次性下载全部
- 经纬度超出 70-140 / 0-60 范围的坐标会被过滤
